# 🌷 LIORA — Flower E-commerce Website

A modern and responsive flower shopping website built using **HTML, CSS, and JavaScript**.

---

## 💖 Features

- 🌸 Beautiful flower product listings
- ❤️ Wishlist system (UI ready)
- 🛒 Shopping cart page
- 🔍 Search bar (UI ready)
- 🎁 Special offers & rewards section
- 🤖 AI assistant page (design ready)
- 📱 Fully responsive design

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (basic interaction)
- Swiper.js (for sliders)

---

## 📂 Pages Included

- `index.html` → Home page
- `flower.html` → Product listing
- `wishlist.html` → Wishlist page
- `cart.html` → Shopping cart
- `checkout.html` → Checkout
- `details.html` → Product details
- `chatbot.html` → AI assistant

---

## 🚀 Project Goal

This project was built as a **final college project** to simulate a real e-commerce experience for flower shopping, focusing on:

- UI/UX design
- Responsive layouts
- Basic e-commerce structure

---

## ⚠️ Note

This is a front-end project.  
Some features like cart and wishlist are currently UI-based and can be extended with JavaScript or backend integration (PHP / database).
